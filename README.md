# PackedMC
A PyQT6 based GUI to manage Minecraft Instances and Mods, using Python 3.14.

## Features
- You can create Minecraft instances and Download mods.
- You can import the profiles from the normal Minecraft Launcher into PackedMC.  
- Mods are automatically updated if available.
- Native support for Minecraft Vanilla and Fabric.
- Play your instances using the standard Minecraft Launcher. No additional Login required.
